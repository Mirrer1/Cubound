# Cubound

Cube + bound, "어딘가로 향하는 큐브의 여행".

작은 큐브가 칸을 하나씩 건너 집을 찾아가는 **미니멀 아이소메트릭 퍼즐 게임**입니다.

칸마다 높이가 있어 내려갈 수는 있어도 올라갈 수는 없고, 상자를 밀어 계단을 만들고 스위치를 눌러 문을 열고 사다리를 옮겨 걸며 길을 내는데, 게임 오버가 없어 조용히 생각만 하면 됩니다.

**Live demo:** https://cubound.vercel.app

## 주요 기능

- **아이소메트릭 필드** — 3D 라이브러리 없이 SVG로만 그리고, 큐브는 6면을 회전시켜 보이는 세 면만 투영합니다.
- **구역 카메라** — 맵이 화면보다 크면 구역으로 나누고, 큐브가 구역을 넘어가면 그 구역이 화면 한가운데 오도록 이동하며 배율을 맞춥니다.
- **풀이 검사기** — 게임과 같은 규칙 함수로 가능한 상태를 전부 펼쳐 최소 이동 수를 구하고, 별점 기준과 보스 제한을 그 값으로 정합니다.
- **별점과 보스** — 최소 이동 수면 별 3개이고, 열 번째 판마다 붙는 보스 제약은 최소 풀이가 쓰는 만큼이라 여유가 없습니다.
- **조작** — 타이틀에서 클리어까지 키보드만으로 가고, 모바일은 화면 어디서 밀어도 되며 연출 중에 눌러도 입력이 밀리지 않습니다.
- **다국어** — 여섯 언어를 기기 설정에 맞춰 보여주고, 번역이 없는 문구는 영어로 내보냅니다.

## 오브젝트

색으로 역할을 나눠 큐브는 블루, 밀고 옮기는 도구는 옐로, 지형은 무채색입니다.

| 오브젝트        | 월드 | 설명                                                                                         |
| --------------- | ---- | -------------------------------------------------------------------------------------------- |
| 상자            | 1    | 밀어서 옮기고 못 밀면 큐브가 그 위로 올라섭니다                                              |
| 스위치          | 1    | 큐브나 상자가 올라가 있는 동안만 연결된 대상이 반응합니다                                    |
| 문              | 1    | 닫히면 한 층 벽, 열리면 바닥 높이                                                            |
| 사다리          | 1    | 주워서 들고 다니다 한 층 높은 칸에 기대 놓고 오릅니다                                        |
| 얼음            | 2    | 도착한 칸이 얼음이면 멈출 때까지 미끄러지고 전체가 이동 1회입니다                            |
| 엘리베이터 발판 | 2    | 연결된 스위치가 눌린 동안 한 층 올라가고 위에 있는 것이 같이 오릅니다                        |
| 무너지는 칸     | 3    | 딛고 있던 것이 떠나면 금이 깊어지고 다 닳으면 사라집니다                                     |
| 짝 칸           | 3    | 밟으면 짝인 칸으로 곧바로 옮겨가고 상자는 옮겨가지 않습니다                                  |
| 움직이는 발판   | 4    | 큐브가 한 번 움직일 때마다 정해진 길을 한 칸씩 오가고 위에 탄 것도 같이 갑니다               |
| 늪              | 6    | 들어가면 두 수를 제자리에서 버둥거린 뒤에야 나가고 상자를 밀어 넣으면 가라앉아 평지가 됩니다 |

새 요소는 몇 판에 하나씩만 내놓고 그 사이 판에서 조합을 연습시키며, 지금은 60판 6월드까지 나와 2사이클 "풀이 우거진 길"을 시작했습니다.

**50판이 한 장(chapter)이고 장마다 세계 색이 다르며**, 목록 헤더의 월드 덩이를 누르면 화면을 갈아 끼우지 않고 그 자리에서 장 고르기로 바뀝니다.

## 스테이지 제작

스테이지는 높이 격자와 오브젝트가 든 JSON 한 장이고, 손으로 풀어 보는 대신 명령줄 도구가 검사합니다.

```
$ pnpm stage:check src/stages/world-1/10.json

  형식  통과
  최소  34수 (best 34 일치)
  제한  41수 (여유 7수)
  밀기  최소 2번
  탐색  상태 352개
  막힘  0개
  대체  34수 풀이 6가지, 제한 안 상태 138개
  구역  1구역 8수, 2구역 6수, 3구역 10수, 4구역 10수
```

막힘이 0개면 되돌릴 수 없는 실수가 없고 대체 풀이가 1가지면 외길이며 구역별 이동 수가 한쪽에 쏠리면 퍼즐이 한 구역에만 몰려 있다는 신호라, 이 값들로 `best`와 보스 제한을 확정합니다.

## 설계 노트

- **순수 함수** — 게임 규칙을 `game/` 아래 순수 함수로 두어 게임과 검사기와 테스트가 한 벌만 공유하고, 규칙을 고치면 어느 스테이지가 깨지는지 바로 드러납니다.
- **연출** — `move()`가 결과를 즉시 돌려주고 화면이 그 사이를 보간해서, 연출 프레임 계산도 진행도 `t`를 받는 순수 함수라 단위 테스트가 붙습니다.
- **별점 기준** — 최소 이동 수 `best`를 검사기로 구하고 테스트가 모든 스테이지를 그 값과 대조해, 맵에 남은 지름길 때문에 별 3개 기준이 조용히 틀어지는 것을 막습니다.
- **성능** — 체감 문제는 Playwright로 먼저 쟀고, CPU를 4배 느리게 두고 프레임 간격을 재서 찾은 원인을 고쳐 상자 밀기 평균 프레임이 28.6ms에서 17.5ms가 됐습니다.

## 시작하기

Node.js 22.12+, pnpm 9가 필요하고 환경 변수는 없습니다.

```bash
pnpm install
pnpm dev
```

| 명령                      | 설명                                            |
| ------------------------- | ----------------------------------------------- |
| `pnpm build`              | 프로덕션 빌드, 타입 검사 포함                   |
| `pnpm test`               | Vitest 단위 테스트                              |
| `pnpm e2e`                | Playwright 스모크 테스트                        |
| `pnpm shot`               | 핵심 화면 캡처, 아이콘과 공유 카드도 다시 찍음  |
| `pnpm shot:stages`        | 스테이지별 장면 캡처                            |
| `pnpm stage:check <경로>` | 스테이지 형식 검사와 난이도 지표, 생략하면 전체 |

## 프로젝트 구조

```
apps/web/
  src/
    game/         # 순수 로직 — 규칙 / 풀이 검사기 / 형식 검사 / 가림 처리 / 진행 / 이어하기 / 좌표 / 카메라
    stages/       # 스테이지 JSON — world-1 ~ world-6
    store/        # Zustand — 게임 상태 / 연출 / 입력 대기열 / 설정
    platform/     # 브라우저 의존 — 저장 / 입력 / 주소 / 탭 제목
    components/   # board 필드와 연출 / guide 스텝 가이드 / ui 공용
    screens/      # 타이틀 / 스테이지 선택 / 게임
    i18n/         # 언어별 사전
  public/         # 아이콘 / manifest / 공유 카드 / robots.txt
  tools/          # pnpm stage:check
  e2e/            # Playwright 스모크와 화면 캡처
apps/server/      # 비어 있음, 나중에 NestJS
packages/         # 비어 있음, 나중에 web과 server 공용 코드
docs/             # 기획, 설계, 디자인 브리프
```

주소는 `#/` 타이틀, `#/stages/:world` 스테이지 선택, `#/stages/:world/chapters` 장 고르기, `#/play/1-10` 게임입니다.
