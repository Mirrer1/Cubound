# Cubound

작은 큐브가 칸을 하나씩 건너 집을 찾아가는 미니멀 아이소메트릭 퍼즐 게임.

> 개발 중

## 기술 스택

React, TypeScript, Vite, Tailwind CSS, Zustand, Motion, Vitest, Playwright, pnpm 워크스페이스

## 시작하기

Node.js 22.12 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev      # 개발 서버
pnpm test     # 단위 테스트
pnpm e2e      # 브라우저 스모크 테스트
```
