# Cubound Design Brief

> Claude Design에 그대로 전달하는 문서.

## 게임 소개

**Cubound**는 작은 큐브가 칸을 하나씩 건너 **집(구멍)**을 찾아가는 미니멀 퍼즐 게임입니다.

- 아이소메트릭 2.5D 시점 (비스듬히 내려다본 입체 느낌의 2D)
- 필드에는 높이 차이가 있고, 상자, 스위치, 사다리를 활용해 길을 만듭니다
- 게임 오버가 없는 조용하고 차분한 퍼즐
- 이름: Cube + bound(~로 향하는). "어딘가로 향하는 큐브의 여행"

## 타깃 기기

- **웹 (먼저):** 데스크톱 브라우저, 키보드 방향키 조작
- **모바일 앱 (나중에):** 세로 화면 기준, 스와이프와 화면 방향 버튼
- 두 환경 모두 고려한 반응형 레이아웃

## 분위기

- **미니멀, 모노톤, 차분함.** Monument Valley처럼 조용하고 정돈된 느낌
- 귀여운 캐릭터 스타일 **아님** (표정, 파스텔 톤, 둥글둥글한 과장 없음)
- 전체적으로 채도가 낮고, 포인트 컬러도 모노톤에 스며드는 톤
- 색으로 역할을 구분: **나(큐브)는 블루, 쓸 수 있는 것(도구)은 옐로, 나머지는 모노톤**

## 컬러

| 역할                        | 색                   | 설명                 |
| --------------------------- | -------------------- | -------------------- |
| 배경                        | `#F2F1EE`            | 따뜻한 오프화이트    |
| 바닥 윗면                   | `#E3E1DC`            | 밝은 회색            |

## 화면 목록

### 1. 타이틀

- 로고 "Cubound"
- 시작 버튼
- 배경에 작은 아이소메트릭 필드와 큐브를 은은하게 표시

### 2. 스테이지 선택

- 1월드 10스테이지
- 스테이지마다 번호, 잠금 상태, 획득한 별(0~3)
- 10번째는 **보스 스테이지**로 시각적으로 구분

### 3. 게임 플레이

- 중앙: 아이소메트릭 필드
- 상단 HUD: 스테이지 번호와 이름, 이동 횟수
- 재시작 버튼
- 메뉴(스테이지 선택으로 돌아가기) 버튼
- 보스 스테이지: **남은 이동 횟수**를 크게 표시하고, 0이면 재시작 버튼 강조
- 1~2스테이지: 큐브 주변에 방향키 힌트
- 모바일: 하단에 방향 버튼 4개 (대각선 배치)

### 4. 클리어

- 큐브가 구멍에 들어가는 연출 후 표시
- 획득한 별(1~3), 이동 횟수
- 다음 스테이지, 다시 하기, 스테이지 선택 버튼

### 5. 보스 시작 안내

- 보스 스테이지 진입 시 제약을 한 줄로 안내
- 예: "이번 판은 24번 안에 집에 도착해야 합니다"

## 게임 오브젝트

모두 아이소메트릭 시점이고, 윗면, 왼쪽 면, 오른쪽 면의 명암으로 입체감을 냅니다. **코드(SVG 다각형)로 그릴 수 있는 단순한 형태**를 원합니다.

| 오브젝트      | 형태                                                                   | 색                   |
| ------------- | ---------------------------------------------------------------------- | -------------------- |
| 바닥 칸       | 마름모 윗면 + 두 옆면. 높이에 따라 옆면 길이가 달라짐                  | 모노톤               |
| 플레이어 큐브 | 1×1×1 정육면체. 바닥 칸보다 작게                                       | 블루                 |
| 상자          | 큐브와 같은 크기의 정육면체. 플레이어와 구분되는 디테일 (모서리 선 등) | 옐로                 |
| 스위치        | 바닥에 붙은 납작한 원 또는 사각 버튼. 눌림 상태 표현                   | 옐로                 |
| 문            | 열림과 닫힘 상태가 구분되는 벽 형태                                    | 모노톤 + 옐로 포인트 |
| 사다리        | 바닥에 놓인 상태와 벽에 세운 상태, 큐브가 든 상태                      | 옐로                 |
| 목표 구멍     | 바닥이 파인 마름모 형태                                                | 진한 회색            |

## 모션 방향

- 큐브 이동: 한 칸씩 톡 옮겨가는 짧고 부드러운 움직임
- 막혔을 때: 제자리에서 살짝 흔들림
- 낮은 칸으로 내려갈 때: 가볍게 떨어져 착지
- 클리어: 큐브가 구멍으로 쏙 들어감
- 전체적으로 과장 없이 짧고 절제된 모션

## 요청 사항

1. 위 5개 화면의 데스크톱과 모바일 세로 레이아웃
2. 게임 오브젝트 스타일 (상태별)
3. 로고 "Cubound" (모노톤. 예를 들어 **o**를 구멍 모양으로 하는 식의 포인트 가능)
4. 앱 아이콘
