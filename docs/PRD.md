# Cubound PRD

작은 큐브가 칸을 하나씩 건너 **집(구멍)**을 찾아가는 미니멀 아이소메트릭 퍼즐 게임.

## 한 줄 소개

"작은 큐브의 집 찾기 여행"

이름 **Cubound** = Cube + bound(~로 향하는). homebound처럼 어딘가로 향하는 큐브라는 뜻.

## 배경과 방향

- Bloxorz(블록을 굴려 구멍에 넣는 퍼즐)와 목표는 비슷하지만, 큐브 모양은 항상 1×1×1로 고정한다
- 재미는 **필드와 오브젝트 활용**에서 나온다. 젤다 사당처럼 규칙 몇 개가 서로 섞여 **풀이법이 여러 개** 나오는 퍼즐을 지향한다
- 게임 오버와 스트레스 없이 조용히 생각하는 퍼즐

## 성격과 제약

- 개인 프로젝트. 트래픽은 거의 없을 것으로 예상
- 운영비 **0원**. 서버와 DB 없이 시작한다
- 웹 먼저 출시하고, 이후 안드로이드와 iOS 앱으로 출시한다 (Capacitor)
- 개발 PC는 오래된 Windows라 가벼운 스택을 쓴다

## 핵심 규칙

| 항목      | 규칙                                                                              |
| --------- | --------------------------------------------------------------------------------- |
| 큐브      | 1×1×1 정육면체. 모양은 변하지 않음                                                |
| 이동      | 방향키로 한 칸씩                                                                  |
| 목표      | 목표 구멍 칸에 들어가면 클리어                                                    |
| 필드      | 칸마다 높이가 있음. **내려가기는 자유**, **올라가려면 도구 필요** (한 번에 한 층) |
| 실패      | **없음.** 필드 밖으로는 이동 불가(제자리에서 살짝 흔들림)                         |
| 막혔을 때 | **재시작 버튼**으로 스테이지 처음부터. 되돌리기는 없음                            |
| 별점      | 최소 이동 수에 가까울수록 ★3. 최소 이동 수는 풀이 검사기로 자동 계산              |

### 조작

아이소메트릭 화면 기준 대각선 방향.

| 키  | 화면상 방향 |
| --- | ----------- |
| ↑   | 오른쪽 위   |
| →   | 오른쪽 아래 |
| ↓   | 왼쪽 아래   |
| ←   | 왼쪽 위     |

- 1~2스테이지에서는 큐브 주변에 방향 힌트를 표시한다
- 모바일(앱 버전)은 스와이프와 화면 방향 버튼을 둘 다 지원한다

## 오브젝트 (1월드)

색으로 역할을 구분한다. 조작할 수 있는 도구는 모두 옐로.

### 📦 상자

밀어서 옮기는 도구. 계단, 구멍 메우기, 스위치 누르기에 쓴다.

| 상황                          | 결과                     |
| ----------------------------- | ------------------------ |
| 상자 뒤에 또 상자             | 안 밀림 (한 번에 하나만) |
| 상자 뒤가 벽이거나 더 높은 칸 | 안 밀림                  |
| 낮은 칸 쪽으로 밀기           | 떨어져서 아래층에 놓임   |
| 빈 구멍으로 밀기              | 구멍을 메워 바닥이 됨    |
| 목표 구멍으로 밀기            | 안 밀림                  |
| 큐브가 상자 위로 이동         | 가능. 한 층 높이의 발판  |

### 🔘 스위치

- 무언가(큐브 또는 상자)가 **올라가 있는 동안만** 연결된 문이나 발판이 작동한다
- 상자를 올려 두면 계속 눌린 상태가 된다

### 🪜 사다리

- 주워서 들고 다닌다. **한 번에 1개만** 들 수 있다
- 한 층 높은 칸 앞에 놓으면 올라갈 수 있다
- 다시 주워서 재사용할 수 있다

## 스테이지 구성 (1월드)

3의 배수 스테이지에서 새 요소를 하나씩 소개하고, 10에서 전부 합친다. 튜토리얼 문구 대신 맵으로 가르친다.

| 스테이지 | 역할                                    |
| -------- | --------------------------------------- |
| 1~2      | 기본 이동, 높이 개념 (내려가기만 가능)  |
| **3**    | **📦 상자 등장**                        |
| 4~5      | 상자 연습                               |
| **6**    | **🔘 스위치 등장**                      |
| 7~8      | 상자로 스위치 눌러 두기 연습            |
| **9**    | **🪜 사다리 등장**                      |
| **10**   | **👑 보스: 모든 요소 + 이동 횟수 제한** |

### 보스 스테이지

- 10단위 스테이지는 보스. **보스마다 고유한 제약이 하나씩** 있다
- 시작할 때 제약을 한 줄로 알려준다
- 제약에 걸려도 게임 오버는 없고, 재시작하면 된다

**1월드 보스 (10): 이동 횟수 제한**

- 남은 이동 횟수를 크게 표시한다
- 한 칸 이동, 상자 밀기, 사다리 놓기와 줍기를 모두 1회로 센다
- 0이 되면 큐브가 멈추고 재시작 버튼을 강조한다
- 제한 = 최소 이동 수 + 약간의 여유 (예: 최소 20이면 24)
- 사다리는 9에서 해본 수준으로 쓰고, 어려움은 상자와 스위치 조합에서 준다

**이후 보스 제약 후보:** 무너지는 바닥, 한 번뿐인 도구, 어두운 필드, 순서 스위치, 따라오는 적

## 게임 흐름

- 화면: 타이틀 → 스테이지 선택 → 게임 → 클리어
- 해금: 앞 스테이지를 클리어하면 다음 스테이지가 열림 (별 개수 무관)
- 저장: 진행 상황과 스테이지별 최고 별점을 기기에 저장

## MVP 범위

**포함**

- 1월드 10스테이지
- 상자, 스위치, 사다리
- 이동 횟수 제한 보스
- 별점, 해금, 기기 저장
- 풀이 검사기 (풀이 가능 여부와 최소 이동 수)
- 웹 배포

**제외 (나중에)**

- 되돌리기
- 사운드
- 힌트
- 다국어
- 스테이지 에디터와 공유
- 랭킹, 로그인, 클라우드 저장
- 모바일 앱 출시

## 이후 확장

- **월드 추가:** 11~20은 새 오브젝트(얼음, 물, 엘리베이터 발판 등)를 가진 2월드
- **모바일 앱:** Capacitor로 안드로이드와 iOS 출시
- **수익화 아이디어 (여유 되면):**
  - 큐브 스킨 (소재, 색, 이동 효과, 클리어 효과)
  - 힌트
  - 월드 팩
  - 능력이 있는 큐브는 퍼즐 난이도와 별점을 망가뜨려서 넣지 않는다
- **서버 기능 (필요해지면):** 랭킹, 이어하기, 스테이지 공유. NestJS와 무료 DB를 붙인다
